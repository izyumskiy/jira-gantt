# Spec delta — ai-analysis (add-share-beta)

## ADDED Requirements

### Requirement: Доля потока — бета-распределение
Доля эпика в потоке команды SHALL выбираться в каждом прогоне из Beta(p₀·m₀ + k, (1 − p₀)·m₀ + n − k),
где k и n — задачи эпика и все задачи команды в окне доли, p₀ — доля часов эпика в плане ближайших
спринтов команды (m₀ = 10), без плана — p₀ = ½, m₀ = 1. Выборка SHALL быть не ниже четверти средней.

#### Scenario: План уточняет историю
- **WHEN** у команды 5 задач эпика из 100, а в плане эпик занимает 20% часов
- **THEN** доля выбирается из Beta(7, 103)

#### Scenario: Разброс срока
- **WHEN** доля случайная, а не постоянная
- **THEN** разница P95 и P50 разработки больше, чем с постоянной долей
