# Spec delta — ai-analysis (add-llm-adjustments)

## ADDED Requirements

### Requirement: Блокировки по загрузке людей
LLM SHALL получать загрузку каждого исполнителя задач эпика по ближайшим секциям: ёмкость (рабочие дни
по календарю × часов в дне), загрузку, разбивку по эпикам (этот эпик, другие эпики портфеля, прочая
работа) и перегруз. Блокировка из ответа SHALL приниматься, только если эпик-блокер есть в портфеле или
равен `null` (прочая работа), люди — среди исполнителей задач эпика, секции — из переданных. Принятая
блокировка SHALL передаваться в расчёт (US-4) с задержкой из перегруза и уверенностью.

#### Scenario: Блокировка принята
- **WHEN** LLM указывает: «Иванов перегружен EP-7 в секциях 25–26, уверенность 0,7»
- **THEN** в расчёт идёт задержка из перегруза Иванова задачами EP-7 в этих секциях, в 70% прогонов

#### Scenario: Человек не из эпика
- **WHEN** LLM указывает человека, у которого нет задач эпика
- **THEN** блокировка отброшена

### Requirement: Заглушки от LLM
LLM SHALL получать задачи эпика с признаком «заглушка по настройке» и MAY назвать другие открытые задачи
эпика заглушками с причиной. Названные задачи SHALL исключаться из остатка разработки вместе с
заглушками по признакам. Задача чужого эпика SHALL отбрасываться.

#### Scenario: Сопровождение приёмки
- **WHEN** LLM называет заглушкой «Сопровождение БТ» этого эпика
- **THEN** задача не входит в остаток разработки, в списке задач помечена «заглушка БТ (LLM)»

### Requirement: Поправки приёмки
Коэффициент к сроку приёмки SHALL обрезаться в 0,5…2,0 и умножать выбранный срок приёмки в каждом
прогоне. Период отсутствия заказчика с уверенностью ≥ 0,6 SHALL делать его дни нерабочими для приёмки.

#### Scenario: Коэффициент за границей
- **WHEN** LLM возвращает `bt_factor: 5`
- **THEN** в расчёт идёт 2,0

### Requirement: Проверка ответа
Ответ SHALL проверяться по схеме; при ошибке SHALL выполняться один повторный запрос с указанием ошибки;
при повторной ошибке анализ SHALL выполняться без поправок LLM с пометкой в объяснении.

#### Scenario: Неразбираемый ответ дважды
- **WHEN** LLM дважды возвращает не JSON
- **THEN** срок посчитан без поправок, в объяснении — «поправки LLM не получены»

### Requirement: Отметки пользователя
«Не учитывать» у поправки SHALL сохраняться и действовать при «Пересчитать» и следующих «Новых
анализах», даже если LLM предложит ту же поправку снова.

#### Scenario: Отключённая блокировка
- **WHEN** пользователь отключил блокировку EP-7 и запустил «Новый анализ»
- **THEN** блокировка EP-7 в расчёт не идёт
