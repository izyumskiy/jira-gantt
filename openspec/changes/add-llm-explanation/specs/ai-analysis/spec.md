# Spec delta — ai-analysis (add-llm-explanation)

## ADDED Requirements

### Requirement: Текст объяснения
После расчёта плагин SHALL запрашивать у LLM объяснение по факторам: 3–5 предложений, начиная с главной
причины, на языке интерфейса. Каждое число и каждая дата в тексте SHALL находиться в факторах; иначе
SHALL выполняться один повтор, а затем — шаблонный текст (US-5).

#### Scenario: Лишнее число
- **WHEN** в тексте LLM есть дата, которой нет в факторах, и повтор тоже с ошибкой
- **THEN** показывается шаблонное объяснение

#### Scenario: Пересчитать
- **WHEN** пользователь нажимает «Пересчитать»
- **THEN** объяснение — шаблонное, запросов к LLM нет
