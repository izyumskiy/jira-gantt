# Change: add-llm-explanation (US-9. Объяснение срока от LLM)

## Why
Шаблонное объяснение (US-5) перечисляет факторы, но не говорит, какой из них главный и почему.

**История.** Как менеджер, я хочу короткое объяснение срока человеческим языком, начиная с главной
причины, чтобы сразу понимать, что двигает срок.

## What Changes
- Второй запрос к LLM после расчёта: по факторам — 3–5 предложений, с главной причины.
- Каждое число и дата в тексте проверяются по факторам; лишнее — один повтор, затем шаблон.

Основание — ТЗ, блок А5.2.

## Impact
- **Код:** `src/llm/explanation.js`; `aiAnalysis.js` (сохранение текста).
