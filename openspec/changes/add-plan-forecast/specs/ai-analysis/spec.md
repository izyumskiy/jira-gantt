# Spec delta — ai-analysis (add-plan-forecast)

## ADDED Requirements

### Requirement: Разработка от плана спринтов
Задачи разработки эпика в спринтах с датами SHALL заканчиваться в конце своего спринта плюс перенос,
выбранный из истории групп «эпик × команда × спринт»; задачи одной группы SHALL переноситься вместе.
Задачи без спринта SHALL считаться по темпу закрытий. Конец разработки SHALL быть позднейшим из двух.

#### Scenario: Переносов в истории нет
- **WHEN** все задачи разработки в спринте до 20.11, а в истории ни одна группа не переносилась
- **THEN** P95 разработки — 20.11

### Requirement: Задачи сопровождения
Задача сопровождения (по признакам настройки или по LLM) SHALL NOT входить в остаток разработки и в
бизнес-тест; остаток SHALL делиться между командами по исполнителям.

#### Scenario: Аналитик поддерживает проект
- **WHEN** у команды «Аналитика» открыта только задача «Поддержка проекта»
- **THEN** у команды нет остатка, узким местом она не становится

### Requirement: Бизнес-тест по плану заглушек
Без истории приёмок срок БТ SHALL браться как рабочие дни от конца последнего спринта разработки до
конца последнего спринта заглушек; кончаются в одном спринте — сверх разработки ничего не добавляется.

#### Scenario: Заглушки после разработки
- **WHEN** разработка в спринте до 04.11, заглушки до 02.12
- **THEN** бизнес-тест — 20 р.д. после конца разработки
